# Product

## Register

product

## Users

Developers who run AI CLI coding tools from a mobile or LAN control surface while keeping the actual execution bounded to trusted desktop workspaces. They are switching between coding conversations, reviewing tool output, and starting real daemon runs without exposing a raw remote terminal.

## Product Purpose

Provide a phone-friendly control plane for Claude, Codex, OpenCode, and related CLI adapters. Success means a user can choose the correct workspace, start or resume a coding session, understand run status, and inspect output while preserving explicit workspace, pairing, token, and approval boundaries.

## Brand Personality

Calm, technical, trustworthy. The interface should feel like a focused coding instrument: dense enough for real work, quiet enough for long sessions, and explicit about safety-critical state.

## Anti-references

Avoid generic SaaS dashboards, decorative terminal cosplay, neon hacker visuals, and modal-heavy flows that obscure where a CLI run will execute. Avoid any UI that makes workspace selection feel casual or ambiguous.

## Design Principles

- Make execution context visible before action.
- Prefer earned familiarity over novelty.
- Keep safety boundaries legible without slowing expert flow.
- Use quiet hierarchy and restrained accent color for selection, focus, and state.
- Optimize for short glances during active coding sessions.

## Accessibility & Inclusion

Target readable contrast in dark environments, clear focus and selected states, reduced decorative motion, and text labels that remain understandable without relying on color alone.
