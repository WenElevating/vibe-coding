# V1.3 Local Release Checklist

## Windows Daemon

- Dev start: `DAEMON_MODE=dev DEV_ADAPTERS=1 npm run start:daemon`.
- Release start: `DAEMON_MODE=release npm run start:daemon`.
- Config location: local environment variables for V1.3.
- Diagnostic bundles: `.omx/diagnostics/*.json`.
- LAN mode: set `DAEMON_HOST=0.0.0.0`; Windows Firewall may prompt.
- Reset/uninstall: stop daemon and remove local `.omx/diagnostics` plus future database files.

## Android App

- Dev flavor target: synthetic adapters visible and smoke endpoint enabled.
- Release flavor target: synthetic/dev APIs hidden.
- Build command target: `flutter build apk --flavor release` once Flutter project shell exists.

## Release Gate

- `npm run lint` passes.
- `npm test` passes.
- Direct Dart SDK `dart.exe analyze mobile/lib/...` passes.
- No PTY, remote terminal, arbitrary shell/cwd/args API.
- Diagnostic bundle redaction test passes.
- Release mode disables `/api/e2e/smoke`.
- Release notes and rollback notes are updated.

## Rollback

- Stop the daemon.
- Restore previous package/archive.
- Keep paired devices/workspaces/runs/events untouched.
- Re-run `/api/health` and `/api/version` after restart.
