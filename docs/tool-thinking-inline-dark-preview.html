这是一个 LAN AI CLI 控制面板项目，用 Flutter 做手机端界面，通过局域网远程控制桌面上的 AI 编码工具。

核心功能：

  • 手机端控制：选择工作区、启动或恢复编码会话、查看运行状态和输出
  • 安全边界：配对认证、Token 鉴权、工作区白名单、审批审计
  • 多适配器：支持 Claude、Codex、OpenCode 等 CLI 工具
